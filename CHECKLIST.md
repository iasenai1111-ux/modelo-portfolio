# Checklist antes de divulgar

## Perfil
- [ ] Foto e nome real
- [ ] Bio de uma linha dizendo sua área
- [ ] README do perfil preenchido, sem texto de modelo sobrando
- [ ] Até seis repositórios fixados

## Cada projeto
- [ ] Nome que descreve o projeto (`analise-vendas-2025`, e não `projeto1`)
- [ ] Descrição curta preenchida no repositório
- [ ] README com problema, resultado, como rodar e tecnologias
- [ ] Pelo menos uma imagem do resultado
- [ ] O código roda seguindo só as instruções do README
- [ ] Nenhuma senha, token ou chave de API no código ou no histórico
- [ ] Nenhum dado pessoal real de terceiros
- [ ] Créditos a quem você usou como base

## Teste final
- [ ] Abri meu perfil em aba anônima e entendi em 10 segundos quem sou e o que faço
- [ ] Pedi para um colega clonar e rodar um projeto
